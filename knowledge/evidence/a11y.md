# Evidence log — dimension `a11y` (accessibility and verification practice)

- **Date:** 2026-10-14
- **Scope:** accessibility rules an AI must follow when writing itch.io custom CSS (profile, project, devlog, jam), plus a reproducible verification workflow.
- **Tools:** curl 8.x (Git Bash), headless **Chrome 155.0.8059.40** driven over the Chrome DevTools Protocol from **Node 22.13** (built-in `WebSocket`), Python 3.12.6. No logged-in session and no form submissions. The shared Browser pane and the user's own Chrome were **not** used. Chrome ran with an isolated `--user-data-dir` in the scratchpad.
- **itch static build observed:** `static.itch.io/{user,game,jam,main}.css?1791970861`. At 15:06 the same day the pages referenced `?1791981660`, and all four stylesheets were **byte-identical** to the earlier build (`cmp`), so the counts below hold for both. Don't key anything on the query string; it changes without CSS changes.
- **Test code (all written for this log):** `knowledge/evidence/a11y-tests/`. Raw third-party downloads (itch HTML/CSS, MDN BCD JSON) were kept **only in the scratchpad**. None of them are copied here.

### 1.2 Local harness (reproducible)

```sh
curl -sS -A "$UA" -o raw/profile.html https://<user>.itch.io/
curl -sS -A "$UA" -o raw/user.css "https://static.itch.io/user.css?<build>"
python -I a11y-tests/build-harness.py raw/profile.html pages/profile-local.html \
  "https://static.itch.io/user.css?<build>=>../raw/user.css"
```

`build-harness.py` strips every `<script>` and the csrf meta. It also rewrites URLs to local copies; each pair is written `old=>new`. (Until the 2026-10-14 verification the separator was a single `=`, which broke itch CDN image URLs, because they contain base64 `==` padding.)

⚠️ Stripping scripts freezes JS-managed state, so the harness is **not** a faithful "logged-out visitor with JS" view for those elements:

- `ul#user_tools` keeps its `hidden` class. itch's `user.min.js` (`I.UserUserTools`) removes it about 200 ms after load.
- Thumbnails keep `data-lazy_src` and get no `src`.

Start Chrome with:

```sh
chrome --headless=new --remote-debugging-port=9333 --user-data-dir=<scratch>/chrome-profile about:blank
```

Then run each script with `node <script> file:///<abs path to page> [...]`. `cdp.mjs` exposes `openPage(url,{width,height,media,fontSize,touch})`. It uses `Emulation.setDeviceMetricsOverride`, `Emulation.setEmulatedMedia` (prefers-reduced-motion, forced-colors, prefers-contrast, prefers-reduced-transparency), `Page.setFontSizes` (default font size), `Emulation.setTouchEmulationEnabled`, `Accessibility.getPartialAXTree` / `getFullAXTree`, `Input.dispatchKeyEvent` (Tab) and `Input.dispatchTouchEvent`.

| Script | Test |
|---|---|

| `t6-reflow.mjs` | horizontal overflow at 320/375/640/800/1280 px with a 16 px and a 32 px default font |

### 2.3 Keyboard focus (`t3*`)

Tab order on the logged-out profile without JS:

1. "Follow <name>" (outside `#wrapper`, `opacity:0`, y=-10). This is a **no-JS artifact**: with JS, itch removes `.hidden` after ~200 ms, and below 960px `.hidden` never sets opacity:0. Real visitors see a visible, fixed "Follow" button in the top-right corner as the first stop.
2. Each card's title link (thumbnails are skipped). On this profile the author link is hidden by itch (`.user_page .game_grid_widget.user_game_grid .game_cell .game_author{display:none}`). In purchases and collections rows, cards have **two** stops: title, then author (verified on leafo.itch.io with `v6-cardstops.mjs`).
3. Footer links

Every stop has computed `outline: auto 1px rgb(54,18,117)` and `:focus-visible` = true.

`.game_cell` shows `:focus-within` = true while its title link is focused, but its hover `transform` stays `none`.

Zoomed screenshots:

- The `auto` ring is drawn as an inner #361275 line plus an outer white line.
- The ring around a game-title link is cut off on its top and left edges. The cause is `.game_title{overflow:hidden;-webkit-line-clamp:2}`, verified as computed `overflow:hidden`.
- A custom ring of `3px solid` with a 3px offset on the link is clipped the same way.
- `#wrapper .game_cell:focus-within{outline:3px solid;outline-offset:3px}` renders completely and follows the 18px border-radius.
- `#wrapper a{outline:none}` leaves no indicator at all.

### 2.6 Reflow and text size (`t6-reflow.mjs`, real profile, reduced motion)

| default font | width | h-scroll | title font | grid cols |
|---|---|---|---|---|
| 16 | 320 / 375 / 640 / 800 / 1280 | no | 48 / 48 / 64 / 80 / 96 px | 1 / 1 / 2 / 2 / 4 |
| **32** | **320 / 375** | **yes (scrollWidth 513; 479 in the verification re-run)** | 96 px | 1 |
| 32 | 640 / 800 / 1280 | no | 96 / 96 / 128 px | 2 / 2 / 4 |

The exact overflow width varies between runs because the profile's external `live.css` randomizes the title's per-letter fonts on every visit.

The offender was `.custom-title` (`white-space:nowrap` with `font-size:clamp(3rem,10vw,6rem)`). Injecting `white-space:normal;max-width:100%;padding-inline:0` made every width pass.

⚠️ That fix splits the name mid-word, because each letter is an inline-block and lines may break between atomic inlines. The second pass (§5) measured "Mir / oksh / i" at 320 px and "Miro / kshi" at 375 px. Keeping `nowrap` and dropping the rem floor, `font-size:min(10vw,6rem)`, removed the overflow at both widths **and** kept "Mirokshi" on one line (`r2-titlewrap.mjs`).

With a 32px default font, `body` stays **14px** and the bio stays 16px. itch sizes its text in px, so only page zoom scales it.
